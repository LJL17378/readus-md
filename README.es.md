# Readus.md

Readus.md es una bifurcación de Quiet.md 0.1.14 con biblioteca de lectura, marcadores por párrafo, progreso y documentos relacionados en carpetas de trabajo.

Descarga las versiones de prueba desde Releases de este repositorio. Los instaladores de Quiet.md no incluyen estos cambios. Por ahora se distribuye una prueba para Mac con Apple Silicon y macOS 13+, sin notarización de Apple. La nueva interfaz de lectura admite chino simplificado e inglés.
