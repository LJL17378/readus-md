# Readus.md

Readus.md est un fork de Quiet.md 0.1.14 ajoutant une bibliothèque de lecture, des signets par paragraphe, le suivi de progression et des documents reliés dans les dossiers de travail.

Téléchargez les versions de test depuis Releases de ce dépôt. Les installateurs Quiet.md ne contiennent pas ces ajouts. La version proposée cible les Mac Apple Silicon sous macOS 13+, sans notarisation Apple. La nouvelle interface de lecture est disponible en chinois simplifié et en anglais.
