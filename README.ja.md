# Readus.md

Readus.md は Quiet.md 0.1.14 を基に、本棚、段落ブックマーク、読書進捗、作業フォルダのナレッジライブラリを追加したフォークです。

テスト版はこのリポジトリの Releases から入手してください。上流の Quiet.md インストーラーには本機能は含まれません。現在の配布対象は Apple Silicon Mac（macOS 13+）で、Apple の公証は未実施です。新しい読書 UI は簡体字中国語と英語に対応しています。
