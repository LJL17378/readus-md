# Readus.md

Readus.md는 Quiet.md 0.1.14를 바탕으로 책장, 문단 북마크, 읽기 진행률, 작업 폴더 기반 지식 라이브러리를 추가한 포크입니다.

이 저장소의 Releases에서 테스트 버전을 받으세요. 원본 Quiet.md 설치 파일에는 이 기능이 없습니다. 현재 Apple Silicon Mac(macOS 13+)용 테스트 패키지를 제공하며 Apple 공증은 받지 않았습니다. 새로운 읽기 UI는 간체 중국어와 영어를 지원합니다.
