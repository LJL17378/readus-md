# Readus.md application icon

The current application mark is a flat blue tile with five offset stacked books and a ribbon bookmark. The user requested blue, multiple books, and a flat style without 3D perspective. It replaces the upstream Quiet.md app icon; no upstream brand artwork was used as a reference.

Created on 2026-11-27 using the built-in imagegen tool. Final edit prompt: a pure flat medium-blue rounded-square app tile; five books in front elevation, ivory pages and pale-blue or white covers, alternating horizontal offsets, a short ribbon bookmark; simple large color masses and small-size legibility; no perspective, shading, texture, printed text or extra symbols; transparent outside the tile.

`app-icon.png` and `app-icon-dev.png` are 1024px PNG assets. The development bundle is identified by its app name, `Readus.md Dev`. `app-icon.ico` wraps a 256px PNG for Windows. The development packager and existing macOS release scripts generate multi-resolution ICNS resources from these PNGs.

The older source artwork beside these files is upstream historical material, not the current Readus.md application mark.
