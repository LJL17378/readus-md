# Readus.md 阅读工作区

书架和知识库使用同一批真实文档。加入书架、阅读和添加书签都不会向 Markdown 正文插入专用标签。

## 书架与进度

打开文档后，点击底部的书本按钮加入或移出书架。移出只改变书架归属，保留原文、书签和阅读记录。

书架可以查看全部、待读、在读和已读。继续阅读区展示最近在读的文档，同一本书只出现一次。阅读页底部显示当前位置；书架保留读到的最远进度。读到文末不会自动宣称读完，可以主动标记已读；重新阅读会清除原有进度，从头开始。

重开文档会按段落文字、相邻上下文和段内比例恢复位置。虚拟列表的百分比是位置估计，不是阅读或理解程度。

## 书签

在阅读页点击底部的书签图标，或使用默认快捷键 ⌘D（Windows/Linux 为 Ctrl+D）。有文字选区时标记选中段落，否则标记当前位置。右侧书签列表可以跳转和移除，侧栏的书签页汇集各文档的书签。快捷键可以在原有设置中调整。

书签按段落定位，暂不表示文字高亮或批注。正文更改后仍会尝试通过文字和上下文寻找原段落；无法确定位置时保留书签并说明原因，不跳到无关内容。

## 知识库

添加工作目录后，可以直接浏览其文档，不需要复制出第二套知识库。知识库视图汇集已打开目录中的文档，结合原有 @文档引用和普通 Markdown 文件链接展示关联。点击“查看引用”浏览相关文档，点击标题打开原文。仅展示当前工作目录集合中已识别的文档关系；网页链接和图片不作为知识文档关联。

文档自身已有的 @引用、反向引用、相对路径处理和移动时链接重写继续使用原引擎。

## 语言

新增阅读界面支持简体中文和英文，使用现有本地化机制。验证包含两种语言的交互、重启恢复及截图，文档标题和正文属于用户内容，不随界面语言转换。

## 后续 Agent 功能的共同验收要求

本轮没有加入内置模型对话功能。原有 CLI/MCP 和外部 Agent 连接能力继续保留。

如果后续实现内置 Agent，API 设置和管理必须与 Agent 一起交付：服务商、接口地址、模型、API Key、连接测试，以及添加、更换、删除配置。密钥应使用本机安全凭据存储，界面遮罩显示，不写入文档、Git、日志或公开构建产物；未配置时应明确引导设置。不得只有聊天面板而没有可用的连接配置。
